# Personal Mini-Toolkit

## What This Toolkit Does

The Personal Mini-Toolkit is a menu-driven Python program containing three useful tools: a Simple Calculator, a To-Do List, and a Number Guessing Game. The program allows the user to select a tool from the main menu and returns to the menu after the tool finishes.

## Tools

- `toolkit_plan.txt` - Contains the planning and design for the Personal Mini-Toolkit.
- `toolkit.py` - Contains the complete menu-driven toolkit with the calculator, to-do list, and guessing game.

## How to Run

Make sure Python is installed on your computer.

Open a terminal in the project folder and run:

```bash
python3 toolkit.py
