PERSONAL MINI-TOOLKIT PLAN

1. TOOLS

Tool 1: Simple Calculator
The calculator asks the user for two numbers and an operation, then calculates and displays the result.

Tool 2: To-Do List
The to-do list allows the user to add tasks, view tasks, and remove tasks while the program is running.

Tool 3: Number Guessing Game
The guessing game asks the user to guess a secret number and gives hints until they guess correctly.
